Cloudflare Pages ile Canlıya Alma Rehberi

Durum: talhayilmaz.xyz alan adınız Cloudflare DNS sunucularına (dolly.ns.cloudflare.com) başarıyla bağlanmıştır. Statik sayfalarınız GitHub reponuzda hazırdır.

Nasıl Canlıya Alınır? (3 Basit Adım):

1
Cloudflare Dashboard'a Giriş:

dash.cloudflare.com adresine gidin. Sol menüden Workers & Pages > Create application > Pages sekmesini seçin.

2
GitHub Reposunu Bağlama:

Connect to Git seçeneğine tıklayın ve talha1yilmaz/talhayilmaz.xyz reposunu seçin. Branch olarak master belirleyin. Build command kısmını boş bırakın (statik HTML olduğu için doğrudan kök dizini sunar).

3
Özel Alan Adı (Custom Domain) Tanımlama:

Pages projesi oluştuktan sonra Custom domains sekmesine geçip talhayilmaz.xyz yazın. Cloudflare DNS otomatik olarak CNAME kaydını bağlayacak ve ücretsiz SSL sertifikasını 1-2 dakika içinde aktif edecektir.
